# Landing de presentación de AgroAlerta

Página HTML estática de presentación del proyecto, pensada para integrarla en la web de 10P Software o publicarla como página independiente.

## Vista previa local

Abrir `landing/index.html` en un navegador. No requiere Node, compilación ni dependencias externas.

## Contenido

- Estado claramente indicado como **Proyecto en desarrollo**.
- Descripción general de AgroAlerta y sus capacidades previstas.
- Maquetas responsive de la pantalla principal, alertas y parcelas.
- Sección de arquitectura y fuentes de datos.
- Advertencia explícita de que las pantallas son conceptuales y los datos de ejemplo no son mediciones reales.
- Enlace de vuelta a la web de 10P Software.

## Integración en 10P Software

Esta landing se ha añadido en una carpeta independiente para no sustituir ni modificar la web actual. Puede publicarse como página separada o trasladarse a la sección de proyectos de la web principal cuando se confirme el repositorio que despliega `10psoftware.web.app`.

No se presenta como una app terminada ni se afirman como productivas las integraciones que todavía requieren validación.
